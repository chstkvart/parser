# Где дешевле?

Сайт для сравнения цен на маркетплейсах. Вводите запрос (например, «iPhone 16», «корм для кошек», «стиральная машина») — сайт ищет товар на **Wildberries**, **Ozon**, **Яндекс Маркете** и **Мегамаркете**, показывает по одному предложению с каждого и подсвечивает самое дешёвое.

- Бэкенд — Python, [FastAPI](https://fastapi.tiangolo.com/), парсинг через [Playwright](https://playwright.dev/python/) (настоящий браузер Google Chrome).
- Фронтенд — одна страница на HTML/CSS/JavaScript без фреймворков, её отдаёт сам бэкенд.

## Как выбирается предложение

С каждого маркетплейса берётся одно предложение:

1. **Поиск по ключевым словам.** Каждое слово запроса должно встречаться в названии или описании товара. Учитываются окончания («смартфоны» ↔ «смартфон») и популярные русские написания брендов («айфон» → iphone, «самсунг» → samsung и т.п.). Аксессуары вроде «Чехол для iPhone 16» отсеиваются, если в запросе нет слова «чехол».
2. **Только популярные и высоко оценённые.** Выдача маркетплейса берётся в порядке популярности (на Ozon — по рейтингу). Из первых 40 подходящих товаров выбирается лучший по рейтингу с учётом числа оценок: 5.0 при двух оценках не обгонит 4.9 при трёх тысячах.
3. **Всегда есть результат.** Если ни один товар не содержит всех слов запроса, берутся товары с наибольшим совпадением, а в крайнем случае — верх выдачи самого маркетплейса.

Карточки появляются по мере готовности. Новый поиск можно запустить в любой момент — предыдущий отменяется, в том числе на сервере.

## Цены

Показывается та цена, которую маркетплейс показывает покупателю **без входа в аккаунт**:

- **Wildberries** крупно показывает цену с WB Кошельком — она и выводится главной, обычная цена идёт второй строкой. Размер скидки и порог, выше которого Wildberries её не показывает, парсер берёт из настроек самого Wildberries.
- Если вы вошли в аккаунт маркетплейса, он может показать вам другую цену (персональные скидки). Сравнивать удобнее в режиме инкогнито.

## Требования

- Python 3.11+
- Установленный [Google Chrome](https://www.google.com/chrome/) — встроенный в Playwright Chromium маркетплейсы блокируют гораздо чаще
- **Российский IP-адрес** для Ozon и Мегамаркета: с зарубежных адресов они блокируют любые запросы. Если сервер работает не из России, укажите российский прокси в `PROXY_URL`

## Установка и запуск

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python -m playwright install chromium
.\.venv\Scripts\python run.py
```

На Linux/macOS вместо `.\.venv\Scripts\` используйте `.venv/bin/`.

Сайт откроется на http://127.0.0.1:8000. Если порт занят, задайте другой:

```powershell
$env:PORT="8765"; .\.venv\Scripts\python run.py
```

Запускайте через `run.py`, а не напрямую через `uvicorn`: на Windows он включает нужный Playwright режим asyncio.

## Настройки

Задаются переменными окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HOST` | `127.0.0.1` | Адрес сервера. `0.0.0.0` — чтобы сайт был доступен из сети |
| `PORT` | `8000` | Порт сервера |
| `PROXY_URL` | — | Прокси для браузера, например `http://user:pass@host:port`. Нужен для Ozon и Мегамаркета вне России |
| `HEADLESS` | `1` | `0` — показывать окно браузера (удобно для отладки) |
| `BROWSER_CHANNEL` | `chrome` | Какой браузер запускать. Если Chrome не найден, используется встроенный Chromium |
| `PARSER_TIMEOUT` | `60` | Сколько секунд ждать ответа одного маркетплейса |
| `USER_AGENT` | Chrome 141 на Windows | User-Agent браузера |

Не храните `PROXY_URL` с паролем в коде — файлы `.env` исключены из репозитория через `.gitignore`.

## API

- `GET /api/marketplaces` — список маркетплейсов: `[{"id": "wildberries", "name": "Wildberries"}, ...]`
- `GET /api/search/{marketplace}?q=запрос` — лучшее предложение одного маркетплейса. `marketplace`: `wildberries`, `ozon`, `yandex_market`, `megamarket`

Пример ответа:

```json
{
  "marketplace": "wildberries",
  "name": "Wildberries",
  "offer": {
    "title": "PURINA ONE Сухой корм для стерилизованных кошек 3кг",
    "price": 1580,
    "price_regular": 1613,
    "url": "https://www.wildberries.ru/catalog/214164397/detail.aspx",
    "rating": 5.0,
    "reviews": 20003,
    "image": "https://...webp",
    "description": "..."
  },
  "error": null,
  "search_url": "https://www.wildberries.ru/catalog/0/search.aspx?search=...",
  "fetched_at": "2026-10-07T08:26:49Z"
}
```

Если товар не найден или сайт заблокировал запрос, `offer` равен `null`, а в `error` — понятное описание причины.

## Структура проекта

```
run.py                    запуск сервера
app/
  main.py                 FastAPI: API и раздача страницы
  config.py               настройки из переменных окружения
  browser.py              общий браузер, прокси, распознавание блокировок
  matching.py             поиск по ключевым словам и выбор лучшего товара
  models.py               модели данных
  parsers/
    wildberries.py
    ozon.py
    yandex_market.py
    megamarket.py
  static/                 страница: index.html, app.js, style.css
```

Каждый парсер реализует `search(query) -> list[Offer]` (товары в порядке выдачи маркетплейса) и `search_url(query)`. Новый маркетплейс добавляется файлом в `app/parsers/` и строкой в `app/parsers/__init__.py`.

## Ограничения

- Маркетплейсы защищаются от автоматических запросов и часто меняют сайты, поэтому парсеры могут ломаться и требовать доработки.
- Ozon и Мегамаркет не работают с зарубежных IP-адресов — нужен российский прокси. Их парсеры написаны по известной структуре данных этих сайтов, но на живых данных пока не проверялись: при первом запуске с российского IP они могут потребовать доработки.
- Один поиск занимает 15–40 секунд: для каждого маркетплейса открывается браузер.
